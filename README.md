# AUCHAN EAT - Modélisation Objet (UML)

Ce projet consiste à concevoir la modélisation d'une application de livraison de repas en utilisant la méthode de programmation orientée objet (POO) et en représentant la structure à travers des diagrammes UML. L'application permettrait de gérer les utilisateurs, les repas, les commandes et les livraisons.

## Objectifs

- Analyser les entités principales du système (Utilisateurs, Repas, Commandes, Livraisons).
- Créer un diagramme de classes UML pour représenter la structure des données et les relations entre les classes.
- Définir les attributs, méthodes et associations entre les entités, en appliquant les principes de la POO.

## Diagrammes UML

- **Diagramme de classes** : Modélisation des classes principales de l'application (Client, Livreurs, Repas, Commandes, etc.) et de leurs relations (composition, héritage, associations).
- **Diagrammes supplémentaires** : Diagramme de séquence, diagramme de cas d'utilisation, etc., pour illustrer le comportement du système.

## Rapport

Un rapport détaillé expliquant la modélisation orientée objet, les choix de conception des classes, ainsi que les diagrammes UML créés. `rapport.pdf` couvre :

- L'analyse des classes et de leurs relations.
- La justification des choix de modélisation (ex : pourquoi certaines relations sont en héritage ou en composition).
- Les diagrammes UML utilisés pour illustrer la structure du système.

**Outils de modélisation UML** : draw.io
